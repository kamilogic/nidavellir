This update fixes a slowdown that could build up over hours of use with a profile applied.

- Nidavellir now reads only GPU sensors, so the Dashboard shows CPU temperature and voltage as N/A.
- The Core no longer starts a helper process every two seconds to read the GPU.
- Fixed: the game-capture hook of programs like OBS Studio could load into the Core and stall the NVIDIA driver after hours of use, making video stutter and freezing the PC after Exit until a restart.

Every 10 minutes the Core now writes a short health line to C:\ProgramData\Nidavellir\core.log.
