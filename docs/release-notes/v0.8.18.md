Nidavellir 0.8.18 keeps the Forge's power checks reliable when Windows restarts during a run.

- Fixed: after a blue screen at the edge, the run continues once Windows restarts, but the GPU's power readings can then come out a few percent higher. The Forge compared them with readings from before the restart, judged them unreliable, and could skip a profile's lowest safe voltage, publishing one a little higher. Power readings are now only compared with readings taken since Windows last started.

Your forged profiles are kept. A Forge run that was paused before this update cannot be resumed; start a new one.
