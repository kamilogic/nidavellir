Nidavellir 0.8.2 fixes a GPU driver crash that stopped some Forges at factory settings, on cards with 12 GB of video memory or less.

- One of the Forge's graphics tests asked for more video memory than the card has. Windows moved part of it to system memory, and a single frame could take long enough for Windows to reset the GPU driver. The test now stays inside the video memory Windows gives Nidavellir.
- Because the tests changed, profiles forged with earlier versions need a new Forge. Until a Standard Forge qualifies them again, they are shown as previews and are not applied.
