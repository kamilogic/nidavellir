Nidavellir 0.8.14 changes how the Forge finds Godforge, so all three profiles follow one measured rule.

- Changed: Godforge's clock is now measured, not estimated. Starting one step below the fastest clock that passed, the Forge checks how much voltage each clock can use within the power limit, then tests the game-margin pair under it. The first clock that passes is Godforge's.
- Changed: Godforge's voltage is now its own lowest stable voltage plus the game margin, the same rule as Brokkr's Best and Deep Calm. On the test RTX 3060 Ti, the measurements of an earlier run give Godforge 1890 MHz at 937 mV, Brokkr's Best 1800 MHz at 875 mV and Deep Calm 1710 MHz at 825 mV, the profiles its owner uses in games.
- Fixed: a profile could be passed over when failures at other clocks drew a safety line above a voltage that had passed at its own clock. A pass at its own clock now counts.
- The run log now records the GPU temperature when the stock curve is read, since a warmer GPU reads a lower curve.

A run can take up to about an hour longer: Standard and Clean Run now stop at 9 hours, Long at about 20. Your forged profiles are kept. A Forge run that was paused before this update cannot be resumed; start a new one.
