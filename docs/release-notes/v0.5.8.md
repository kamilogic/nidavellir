Nidavellir now has its own icon and uses less of your PC while it waits in the tray.

- Shortcuts, the taskbar button and the tray now show the copper Nidavellir mark.
- While the window is hidden in the tray or minimized, Nidavellir stops refreshing its screens, so it uses almost no CPU in the background.
- Without a Forge run, the main screen refreshes every 2 seconds instead of twice a second.

If a shortcut still shows the old icon after the update, sign out of Windows and back in to refresh the icon cache.
