Nidavellir 0.8.9 lets the Forge test RTX 50-series cards that run below the voltage the Forge asks for.

- Fixed: some cards (seen on the RTX 50 series) stay one voltage step below the one the Forge sets, so the Forge's setting was never used and the run ended without profiles. The Forge now notices this and tries the same clock at the voltage the card actually runs at.
- When you pause a Forge, a summary report is sent too (only if you allowed error reports), so what the run learned helps improve Nidavellir.

Your forged profiles are kept.
