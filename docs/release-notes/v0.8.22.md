Nidavellir 0.8.22 fixes setup on a freshly installed Windows.

- Fixed: on a Windows without the Microsoft Visual C++ runtime, setup stopped with "StartService failed for NidavellirCore: Windows service error 7", and the Nidavellir Core never started. Nidavellir now includes that runtime, so it needs nothing extra installed.

Nothing else changed. Your forged profiles are kept. A Forge run that was paused before this update cannot be resumed; start a new one.
