Nidavellir 0.8.21-diag.1 is a diagnostic update: it improves the reports the Forge sends, so problems on other graphics cards are easier to find. How the Forge tests your card and the profiles it makes are unchanged.

- Changed: a Forge report now carries the full list of tests from the run. On long runs it used to lose the first hours.
- Fixed: the report names the highest voltage that failed at each clock. It named the first one to fail, which could be lower.
- Fixed: the What's new window understands diagnostic updates like this one, so it shows only what changed since your last version.

Your forged profiles are kept. A Forge run that was paused before this update cannot be resumed; start a new one.
