Nidavellir 0.8 keeps an overnight Forge going after a driver crash at factory settings, and can send error reports so problems get fixed for everyone.

- If the GPU driver crashes while the Forge measures your card at its factory settings, Nidavellir now restarts Windows once, after the 2-minute warning, and repeats those checks instead of stopping for the night. If it happens again, it asks you to update the NVIDIA driver.
- Error reports: before your first Forge, Nidavellir asks once whether to send them. With your OK, a report goes out when a Forge fails, and a short summary when it finishes, so fixes reach every user. Reports hold the GPU model, the driver and Windows versions and the run's logs, never your name, your PC's name or your files. You can change this in Settings → Error reports.
- The screen now says a run "continues by itself" only when it really will.
- Fixed: a paused run with an open incident no longer shows a Resume button that would be refused; Recover Forge comes first.

Your forged profiles are kept.
