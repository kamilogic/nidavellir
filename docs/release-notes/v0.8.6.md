Nidavellir 0.8.6 helps the Forge find profiles on cards that cannot reach the top clock of their factory curve when warm, such as the RTX 50 series.

- Improved: when the first test shows the card running below the target clock at full voltage, the Forge continues from the clock the card actually held, instead of trying a few MHz lower and stopping without profiles.
- Improved: if a stock check runs much slower than usual because another program is using the graphics card, the Forge repeats it once. If it is still slow, you are asked to close those programs instead of restarting Windows.
- The Forge log now shows the voltage measured in each test.

Your forged profiles are kept. A Forge run that was paused before this update cannot be resumed; start a new one.
