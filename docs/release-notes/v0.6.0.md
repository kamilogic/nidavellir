Nidavellir 0.6 is a cleanup release: a lighter app with the same profiles and the same safety checks.

- One design: Command Deck is now the only theme, so Settings no longer has a theme option.
- Less background work: Nidavellir tunes NVIDIA GPUs only, so it no longer reads your CPU, memory or motherboard, or checks the Windows hardware error log while its window is open.
- Nidavellir no longer uses the PawnIO driver. If you installed PawnIO only for Nidavellir, you can uninstall it.
- Old tuning code from earlier versions is gone. Your profiles, the Forge and Safe Loop work as before.
- Windows now lists the publisher as "Nidavellir", and the Core Service has a description in Services.

Your forged profiles are kept.
