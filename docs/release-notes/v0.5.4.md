Nidavellir starts faster and responds faster while it runs.

- The Core no longer pauses every few seconds to read CPU and memory details that no screen used, so status, profile changes and the tray respond right away.
- The Core starts about two seconds faster.
- Exit from the tray closes Nidavellir at once; the Core finishes returning the GPU to stock on its own.
- Fixed: an update could stop with "did not exit within 30s" when the previous Core took long to close.
- Fixed: an update could leave the previous Core Service in place.

The Core now keeps a log in C:\ProgramData\Nidavellir\core.log, which helps when something needs a closer look.
