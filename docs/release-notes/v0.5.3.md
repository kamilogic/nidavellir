Updating is now one click on a small button in the corner of the window.

- When a new version is ready, a round update button appears in the corner. Click it and Nidavellir updates and restarts by itself.
- After an update, Nidavellir shows what changed, including any versions you skipped.
- Settings can check for a new version at any time.
- Fixed: an update could fail to replace the Core Service while it was still closing.
- Fixed: a version found earlier stayed on offer after a newer one came out.

During a Forge run, the update waits until the run ends.
