Nidavellir 0.8.17 gives every profile the lowest safe voltage at its clock.

- Fixed: when the Forge tested two voltages at the same clock, a small difference in measured power could pick the higher one. Power readings at one clock vary with temperature, so they no longer choose. A profile now always takes the lowest voltage that passed with the full game margin: the same performance, a little cooler. On the test RTX 3060 Ti, Brokkr's Best from the latest run goes from 1830 MHz at 900 mV to 1830 MHz at 893 mV.

Your forged profiles are updated automatically. If you had applied one of them, apply it again to use its new voltage. A Forge run that was paused before this update cannot be resumed; start a new one.
