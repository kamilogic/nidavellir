Nidavellir 0.8.15 lets the Forge continue on its own after a crash that restarts Windows or the Nidavellir service.

- Fixed: when a test at the edge crashed the driver and the service or Windows restarted (after a blue screen, or the automatic driver or Windows restart), the Forge marked the run as needing your attention and stopped, instead of continuing as automatic continuation promises. It now continues the same run after the restart, without anyone signing in.

Your forged profiles are kept. A Forge run that was paused before this update cannot be resumed; start a new one.
